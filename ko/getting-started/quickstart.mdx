# 빠른 시작

## 1. Root Shell에서 Source 준비

`sudo -i`는 로그인 Shell로 전환되면서 작업 디렉터리가 바뀔 수 있으므로 **Root 전환을 먼저 수행**합니다.

```bash
sudo -i
git clone https://github.com/xdr-labs/OpenXDR-KVM-Installer.git
cd OpenXDR-KVM-Installer
```

## 2. 설치 프로그램 선택

먼저 **[설치 프로그램 선택](/ko/getting-started/choose-installer)**에서 배포 대상과 네트워크 제약을 확인합니다.

```bash
./DP-Installer.sh
./Sensor-Installer.sh
./AIO-Sensor-Installer.sh
```

## 3. DRY_RUN 유지

DRY_RUN은 기본적으로 활성화되어 있습니다. Configuration Menu에서 Version, Credential, NIC, Storage, Deployment Input을 먼저 확인합니다.

## 4. Full Configuration Validation 실행

**OK / WARN / FAIL** 결과를 확인하고 **FAIL을 모두 해결**합니다. WARN은 내용을 확인하여 현재 배포에 허용 가능한 상태인지 판단합니다.

## 5. 실제 실행 전 DRY_RUN 해제

Validation이 통과하고 NIC, IP, Disk, Version, Credential을 다시 확인한 뒤 Configuration Menu에서 **`DRY_RUN=0`**으로 변경합니다.

<Warning>
`DRY_RUN=0`부터는 Network, Storage, Kernel, VM 정의 등 실제 시스템 변경이 수행될 수 있습니다. 원격 작업 중이라면 Console 또는 Out-of-Band 접근을 확보하십시오.
</Warning>

## 6. 실행 방식 선택

- **Auto Execute All Steps** — 첫 미완료 Step부터 자동 진행
- **Execute Specific Step** — 선택한 Step만 실행하거나 Retry

처음 배포하는 경우 일반적으로 **Auto Execute All Steps**를 사용합니다. 실패한 단계의 원인을 수정한 뒤에는 **Execute Specific Step**으로 해당 단계만 재실행할 수 있습니다.

## 7. Reboot 후 Resume

Network 또는 Kernel 단계에서 Reboot가 발생하면 동일 Installer를 다시 실행하고 Auto Execute를 선택합니다. 저장된 State를 기준으로 다음 미완료 Step부터 이어집니다.

<Note>
Installer의 상태와 로그 위치는 **[상태 및 로그](/ko/reference/state-logs)**에서 확인할 수 있습니다. 배포가 중단되었다고 State 파일을 수동으로 앞 단계나 뒷 단계로 변경하지 마십시오.
</Note>
