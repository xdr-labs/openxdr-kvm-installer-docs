# Ubuntu 24.04.3 Server 설치 가이드

이 문서는 OpenXDR KVM Installer를 실행할 서버에 **Ubuntu 24.04.3 Server**를 설치하기 위한 절차를 설명합니다.

## 1. 예시 서버 하드웨어 사양

| 항목 | 상세 내용 |
| --- | --- |
| CPU | Intel Xeon Gold 6542Y × 2 (2.9 GHz, 24코어/48스레드, 하이퍼스레딩, 60MB 캐시, 250W, DDR5-5200 지원) |
| 메모리 | 256 GB (32 GB RDIMM × 8, 5600 MT/s, ECC) |
| OS 디스크 | 1 × 1.92 TB SATA SSD |
| Data Lake 디스크 | 총 23 TB (3.84 TB SATA SSD × 6) — DLm 및 AIO 용 |
| NIC | Broadcom 5720 듀얼 포트 1 GbE (온보드 LOM) |
| NIC | Intel i350 쿼드 포트 1 GbE |
| NIC | Intel E810-XXV 듀얼 포트 10/25 GbE SFP28 |

### 디스크 구성 예시

- **1 × 1.92 TB**
  - Ubuntu 24.04
  - DLm VM
  - DAm VM
- **6 × 3.84 TB**
  - Data Lake

## 2. BIOS 설정 (SR-IOV & 가상화)

<Warning>
OS 설치 전에 반드시 확인해야 하는 설정입니다.
</Warning>

### BIOS 진입 방법

1. 서버 전원 ON
2. **F2** 키를 눌러 **BIOS Setup Utility** 진입

### 필수 BIOS 설정 항목

#### ① CPU 가상화 설정

경로:

```text
System BIOS
 └─ Processor Settings
     └─ Virtual Technology: Enabled
```

- 기본값: **Enabled**
- 반드시 **Enabled** 상태인지 확인

#### ② SR-IOV 글로벌 설정

경로:

```text
System BIOS
 └─ Integrated Devices
     └─ SR-IOV Global Enable: Disabled
```

<Warning>
기본값은 Enabled인 경우가 많지만 반드시 **Disabled**로 유지해야 합니다.
</Warning>

#### ③ NIC 단위 SR-IOV 설정 (X710 / E810)

경로:

```text
Device Settings
 └─ NIC 선택 (Intel X710 / E810)
     └─ Device Level Configuration
         └─ Virtualization Mode: SR-IOV
```

설명:

- SR-IOV는 NIC 장치 단위에서 이미 활성화되어 있으므로 Global SR-IOV를 켤 필요가 없음
- Global SR-IOV를 Enabled로 설정하면 예기치 않은 동작이나 문제를 유발할 수 있음

## 3. Ubuntu 24.04.3 설치 미디어 준비

- ISO 다운로드:
  - https://ubuntu.com/download/server
- UEFI 방식으로 부팅 가능한 USB 생성
- USB는 서버 **후면 USB 포트 (USB 1 또는 2 권장)** 에 연결

## 4. 설치 프로그램 부팅

1. 서버 전원 ON
2. **F11 → Boot Manager**
3. 다음을 선택

```text
One-shot UEFI Boot Menu
 └─ 후면 USB 1 또는 2에 연결된 디스크
```

## 5. Ubuntu 설치 메뉴 선택

GRUB 메뉴가 나타나면 다음 항목을 선택합니다.

### 선택

- **Try or Install Ubuntu Server** (기본 옵션)

### 선택 금지

- **Ubuntu Server with HWE Kernel**

<Warning>
HWE 커널을 선택하면 다음과 같은 네트워크 오류 루프가 발생할 수 있습니다.

```text
Unable to find a medium containing a live file system
Attempt interactive netboot from a URL?
```
</Warning>

## 6. 네트워크 설정 (설치 중)

DHCP가 사용 가능하고 IP가 자동 할당되면:

- 인터페이스 확인
- **Done** 클릭

이 단계에서는 추가 설정이 필요하지 않습니다.

## 7. 디스크 자동 설정 (Guided Storage)

<Warning>
가장 중요한 단계입니다. 디스크 선택에 주의하십시오.
</Warning>

### 디스크 선택이 필요한 경우

- DLm & DAm 배포
- AIO & MDS 배포

### 디스크 선택이 중요하지 않은 경우

- Sensor 전용 배포
  - Ubuntu 설치 디스크는 배포에 영향을 주지 않음

### 설정 방법

1. **Use an entire disk** 선택
2. **1.79 TB / 1.92 TB OS 디스크만 선택**
   - **Data Lake 디스크 선택 금지**
3. 다음 옵션 활성화
   - **Set up this disk as an LVM group**
4. **Done**
5. 변경 사항 확인 후 진행

## 10. 기본 네트워크 설정 (설치 후)

SSH 접속을 위해 고정 IP 설정을 권장합니다.

### Netplan 설정 파일 수정

```bash
sudo vi /etc/netplan/00-installer-config.yaml
```

### 설정 예시

```yaml
network:
  version: 2
  ethernets:
    eno8303:
      dhcp4: no
      addresses:
        - 10.4.0.200/24
      gateway4: 10.4.0.254
      nameservers:
        addresses:
          - 8.8.8.8
          - 8.8.4.4
```

### 설정 적용

```bash
sudo netplan apply
```

## 11. 설정 확인

```bash
ip addr show
ip route
ping 8.8.8.8
```

위 명령이 정상 동작하면 SSH 접속 가능 상태입니다.
