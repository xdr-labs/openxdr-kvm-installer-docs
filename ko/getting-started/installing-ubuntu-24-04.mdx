# Ubuntu Server 24.04 LTS 설치 가이드

이 문서는 OpenXDR KVM Installer를 실행할 서버에 **Ubuntu Server 24.04 LTS**를 설치하기 위한 절차를 설명합니다.

<Note>
이 가이드는 Ubuntu Server **24.04 LTS 계열**을 기준으로 합니다. 새 설치에는 Canonical이 제공하는 최신 24.04 LTS point release를 사용하십시오. **2026년 9월 23일 기준 최신 설치 미디어는 24.04.5 LTS**입니다. 아래 화면 이미지는 24.04.3 환경에서 촬영된 것이므로 최신 point release에서 일부 화면 문구가 달라질 수 있습니다.
</Note>

![Ubuntu Server 24.04 LTS 전체 설치 흐름 개요](/images/Installing-Ubuntu-24.04/1.png)

## 2. BIOS 설정 (SR-IOV & 가상화)

<Warning>
OS 설치 전에 반드시 확인해야 하는 설정입니다.
</Warning>

### BIOS 진입 방법

1. 서버 전원 ON
2. **F2** 키를 눌러 **BIOS Setup Utility** 진입

### 필수 BIOS 설정 항목

#### ① CPU 가상화 설정

경로:

```text
System BIOS
 └─ Processor Settings
     └─ Virtual Technology: Enabled
```

- 기본값: **Enabled**
- 반드시 **Enabled** 상태인지 확인

#### ② IOMMU / Direct I/O 설정

SR-IOV 또는 PCI Passthrough를 사용하는 배포에서는 다음 기능이 활성화되어 있어야 합니다.

- Intel 플랫폼: **VT-d / IOMMU**
- AMD 플랫폼: **AMD-Vi / IOMMU**

메뉴 이름과 위치는 서버 제조사와 BIOS 버전에 따라 다르므로 해당 플랫폼의 펌웨어 문서를 기준으로 확인합니다.

#### ③ SR-IOV 설정 (DP Cluster에서 SR-IOV를 사용하는 경우)

Dell 서버와 Intel X710/E810 계열 NIC에서 SR-IOV를 사용할 때는 **서버 BIOS의 Global/System SR-IOV 설정과 NIC 장치 수준의 SR-IOV 설정을 함께 확인**합니다.

Dell/Intel 가이드의 일반적인 설정 흐름:

```text
System BIOS
 └─ Global SR-IOV: Enabled

Device Settings
 └─ NIC 선택 (Intel X710 / E810)
     └─ Device Level Configuration
         └─ Virtualization Mode: SR-IOV
```

<Warning>
SR-IOV 설정은 서버 모델, NIC, 펌웨어 버전에 따라 다를 수 있습니다. **Global SR-IOV를 일괄적으로 Disabled로 두는 규칙은 적용하지 마십시오.** DP Installer에서 SR-IOV Cluster Interface를 사용할 경우 해당 서버/NIC 제조사 문서에 따라 SR-IOV를 활성화하십시오. Sensor의 단순 PCI Passthrough는 SR-IOV 자체보다 IOMMU/VT-d 활성화가 핵심입니다.
</Warning>

## 3. Ubuntu Server 24.04 LTS 설치 미디어 준비

- ISO 다운로드:
  - https://ubuntu.com/download/server
- UEFI 방식으로 부팅 가능한 USB 생성
- USB는 서버 **후면 USB 포트 (USB 1 또는 2 권장)** 에 연결

## 4. 설치 프로그램 부팅

1. 서버 전원 ON
2. **F11 → Boot Manager**
3. 다음을 선택

```text
One-shot UEFI Boot Menu
 └─ 후면 USB 1 또는 2에 연결된 디스크
```

![Dell Boot Manager에서 Ubuntu 설치 USB 선택](/images/Installing-Ubuntu-24.04/4.png)

## 5. Ubuntu 설치 메뉴 선택

GRUB 메뉴가 나타나면 이 문서의 표준 설치 흐름에서는 다음 항목을 선택합니다.

### 권장 선택

- **Try or Install Ubuntu Server** (기본 옵션)

Ubuntu Server 24.04 LTS에서는 Server 설치가 기본적으로 GA 커널을 사용하며 HWE 커널도 지원되는 선택지입니다. OpenXDR KVM Installer에는 별도의 **HWE Kernel 설치 단계(STEP 02)**가 있으므로, 이 가이드에서는 기본 Server 설치 경로를 사용한 뒤 Installer가 커널 전환을 관리하도록 권장합니다.

<Note>
특정 최신 하드웨어가 설치 단계부터 HWE 커널을 필요로 하는 경우에는 HWE 부팅 옵션을 사용할 수 있습니다. 과거 특정 서버/미디어 조합에서 발생한 부팅 또는 live filesystem 오류를 모든 Ubuntu 24.04 HWE 설치에 일반화하지 마십시오. 하드웨어별 문제가 있으면 최신 24.04 LTS 설치 미디어와 해당 서버 제조사의 지원 정보를 먼저 확인하십시오.
</Note>

## 6. 네트워크 설정 (설치 중)

DHCP가 사용 가능하고 IP가 자동 할당되면:

- 인터페이스 확인
- **Done** 클릭

이 단계에서는 추가 설정이 필요하지 않습니다.

![Ubuntu Server 설치 중 네트워크 설정 화면](/images/Installing-Ubuntu-24.04/6.png)

## 7. 디스크 자동 설정 (Guided Storage)

<Warning>
가장 중요한 단계입니다. 디스크 선택에 주의하십시오.
</Warning>

### 디스크 선택이 필요한 경우

- DLm & DAm 배포
- AIO & MDS 배포

### 디스크 선택이 중요하지 않은 경우

- Sensor 전용 배포
  - Ubuntu 설치 디스크는 배포에 영향을 주지 않음

### 설정 방법

1. **Use an entire disk** 선택
2. **1.79 TB / 1.92 TB OS 디스크만 선택**
   - **Data Lake 디스크 선택 금지**
3. 다음 옵션 활성화
   - **Set up this disk as an LVM group**
4. **Done**
5. 변경 사항 확인 후 진행

![Ubuntu Server Guided Storage 디스크 설정 화면](/images/Installing-Ubuntu-24.04/7.png)

## 8. 프로파일 설정 (예시)

| 항목 | 값 |
| --- | --- |

</Warning>

## 10. 기본 네트워크 설정 (설치 후)

SSH 접속을 위해 고정 IP 설정을 권장합니다.

### Netplan 설정 파일 수정

```bash
sudo vi /etc/netplan/00-installer-config.yaml
```

### 설정 예시

```yaml
network:
  version: 2
  ethernets:
    eno8303:
      dhcp4: false
      addresses:
        - 10.4.0.200/24
      routes:
        - to: default
          via: 10.4.0.254
      nameservers:
        addresses:
          - 8.8.8.8
          - 8.8.4.4
```

### 설정 적용

```bash
sudo netplan apply
```

## 11. 설정 확인

```bash
ip addr show
ip route
ping 8.8.8.8
```

위 명령이 정상 동작하면 SSH 접속 가능 상태입니다.
