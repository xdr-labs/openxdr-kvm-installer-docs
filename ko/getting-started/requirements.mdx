# 요구사항

정확한 자원 크기는 OpenXDR 구성 요소와 실제 워크로드에 따라 달라집니다. 운영 배포 전 Stellar 용량 산정 결과와 현재 설치 프로그램 설정을 함께 확인하십시오.

<Note>
이 한국어 문서의 설치 절차와 화면 예시는 **Ubuntu Server 24.04 LTS**를 기준으로 합니다. 설치 소스에는 일부 이전 Ubuntu/DP 릴리스용 호환 코드가 남아 있으므로, 기존 버전 배포에서는 현재 소스와 대상 OpenXDR 릴리스의 지원 범위를 별도로 확인하십시오.
</Note>

## 공통 요구사항

- 선택한 설치 프로그램가 지원하는 Ubuntu Server
- System 변경을 위한 Root 권한
- BIOS에서 Intel VT-x 또는 AMD-V 활성화
- SR-IOV/PCI passthrough 사용 시 Intel VT-d 또는 AMD-Vi 활성화
- `whiptail`
- VM 배포에 필요한 CPU, 메모리, 로컬 스토리지
- Host Management Connectivity
- Sensor용 추가 SPAN/Data 인터페이스
- 패키지와 Stellar 구성 요소 이미지 다운로드에 필요한 네트워크 접속
- 네트워크/스토리지 변경 전 복구 계획

## OS 기준

이 문서 집합의 운영 절차는 **Ubuntu Server 24.04 LTS**를 기준으로 설명합니다.

현재 Source에는 이전 Ubuntu 또는 과거 DP 릴리스용 호환 코드가 존재할 수 있지만, 이 문서의 24.04 절차가 그대로 적용된다고 가정해서는 안 됩니다. 기존 버전을 배포할 때는 현재 설치 소스, 대상 OpenXDR 버전, Stellar 지원 기준을 함께 확인하십시오.

## 제품별 Sizing

이 공통 페이지를 실제 배포의 용량 산정 기준으로 사용하지 마십시오. 각 Installer 가이드가 제품별 하드웨어 기준을 자체적으로 포함합니다.

- **[DP KVM Installer](/ko/installers/dp)** — DL/DA VM 기본값, Data Lake, Management/Cluster NIC 요구사항
- **[Sensor KVM Installer](/ko/installers/sensor)** — Sensor CPU, Memory, Storage, Management/SPAN 요구사항
- **[AIO & Sensor KVM Installer](/ko/installers/aio-sensor)** — 통합 AIO/Sensor Sizing, Data Lake, SPAN 요구사항

Repository의 일반적인 12 vCPU / 16 GB / 100 GB 값은 일부 Sensor/AIO 설치 점검의 시작 기준일 뿐이며 운영 환경의 용량 산정 값으로 사용해서는 안 됩니다.

<Warning>
NIC 이름 변경, ifupdown 전환, Disk Provisioning은 원격 접속과 기존 데이터를 손상시킬 수 있습니다. Console 또는 Out-of-Band Access를 먼저 확보하십시오.
</Warning>
