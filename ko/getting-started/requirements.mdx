# 요구사항

정확한 자원 크기는 OpenXDR 구성 요소와 실제 워크로드에 따라 달라집니다. Production 배포 전 Stellar sizing과 현재 Installer 설정을 함께 검증하십시오.

<Note>
이 한국어 문서의 설치 절차와 화면 예시는 **Ubuntu Server 24.04 LTS**를 기준으로 합니다. Source Installer에는 일부 이전 Ubuntu/DP 릴리스용 호환 경로가 남아 있으므로, Legacy 배포에서는 현재 Source와 대상 OpenXDR 릴리스의 지원 범위를 별도로 확인하십시오.
</Note>

## 공통 요구사항

- 선택한 Installer가 지원하는 Ubuntu Server
- System 변경을 위한 Root 권한
- BIOS에서 Intel VT-x 또는 AMD-V 활성화
- SR-IOV/PCI passthrough 사용 시 Intel VT-d 또는 AMD-Vi 활성화
- `whiptail`
- VM 배포에 필요한 CPU, Memory, Local Storage
- Host Management Connectivity
- Sensor용 추가 SPAN/Data Interface
- Package와 Stellar Component Image 다운로드에 필요한 Network Access
- Network/Storage 변경 전 Recovery Plan

## OS 기준

이 문서 집합의 운영 절차는 **Ubuntu Server 24.04 LTS**를 기준으로 설명합니다.

현재 Source에는 이전 Ubuntu 또는 과거 DP 릴리스용 호환 코드가 존재할 수 있지만, 이 문서의 24.04 절차가 그대로 적용된다고 가정해서는 안 됩니다. Legacy 배포는 반드시 현재 Installer Source, 대상 OpenXDR 버전, Stellar 지원 기준을 함께 대조하십시오.

## Sensor/AIO 공통 시작 기준

현재 프로젝트 README는 Standard Sensor/AIO 경로의 일반적인 시작 기준으로 **12 vCPU**, **16 GB Memory**, 약 **100 GB Free Storage**를 제시합니다. Production sizing은 더 클 수 있으며 Installer가 일부 Resource를 자동 계산합니다.

<Warning>
NIC 이름 변경, ifupdown 전환, Disk Provisioning은 원격 접속과 기존 데이터를 손상시킬 수 있습니다. Console 또는 Out-of-Band Access를 먼저 확보하십시오.
</Warning>
