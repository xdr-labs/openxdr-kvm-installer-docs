# 문제 해결

전체 Installer를 다시 실행하기 전에 실패한 Layer부터 확인합니다.

## 1. Installer Log 확인

Step 시작/종료와 Command 실행 결과를 확인합니다. 경로는 **[State & Logs](/ko/reference/state-logs)**를 참조하십시오.

## 2. Full Configuration Validation 실행

Package, libvirt, Network Prerequisite, Image, Configuration 문제를 Read-only 방식으로 다시 확인합니다.

## 3. 실패한 Step만 재실행

원인을 수정한 후 **Execute Specific Step**을 사용합니다. Step 기반 구조이므로 하나의 실패 때문에 전체 설치를 다시 시작할 필요가 없습니다.

## 자주 확인할 영역

- CPU Virtualization / IOMMU
- libvirt Service, VM Definition, Virtual Network
- Host NIC, Address, Route
- Disk, PV, VG, LV
- Component Image 및 Download 상태

## 복구 원칙

State를 강제로 앞으로 이동시키지 않습니다. Log를 보존하고 Prerequisite를 수정한 뒤 실패한 Step을 재실행합니다.
