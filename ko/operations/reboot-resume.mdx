# 재부팅 및 이어서 실행

설치 프로그램은 호스트 변경으로 재부팅이 필요해도 전체 배포를 처음부터 다시 시작하지 않도록 진행 상태를 저장합니다.

## 현재 Reboot 지점

현재 스크립트는 다음 단계 이후 자동 재부팅을 수행할 수 있습니다.

- **Step 3** — NIC 이름 변경 / ifupdown 전환 / 네트워크 구성
- **Step 5** — Kernel Tuning

## Reboot 이후

같은 소스와 저장된 작업 상태를 유지한 채 **같은 설치 프로그램**을 다시 실행하고 **Auto Execute All Steps**를 선택합니다. 첫 미완료 단계부터 이어집니다.

## State 원칙

단계가 정상 완료된 경우에만 완료 상태가 기록됩니다. 실패하거나 취소된 단계는 완료 위치를 앞으로 이동시키지 않습니다.

<Note>
실패한 단계를 건너뛰기 위해 상태 파일을 수동으로 변경하지 마십시오. 원인을 해결한 뒤 해당 단계를 다시 실행하는 것이 기본 복구 방법입니다.
</Note>
