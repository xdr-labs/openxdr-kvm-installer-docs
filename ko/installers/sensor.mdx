# Stellar Cyber Open XDR Platform

## Sensor KVM Installer – 사용자 가이드

![OpenXDR KVM Sensor Installer 빠른 참조 가이드](/images/Sensor-Installer/1.png)

## 개요

본 문서는 **Stellar Cyber Open XDR Sensor KVM Installer**에 대한 종합 사용자 가이드입니다.

Ubuntu Server 24.04 LTS가 설치된 KVM 호스트에서 **Stellar Cyber XDR Sensor 가상 머신을 설치, 구성, 검증 및 운영하는 방법**을 설명합니다.

본 가이드는 운영 환경에서 Sensor 노드를 배포하고 관리하는 시스템 엔지니어 및 플랫폼 운영자를 대상으로 합니다.

여기에 설명된 모든 절차는 설치 스크립트의 실제 동작 방식과 설계에 기반하고 있으며, 안정적이고 반복 가능하며 운영적으로 안전한 배포를 보장합니다.

## 1. 시스템 아키텍처

### 아키텍처 개요

Stellar Cyber XDR Sensor는 KVM 가상화를 사용하는 물리 서버 상에서 단일 가상 머신으로 배포됩니다.

설치 프로그램은 다음 구성 요소를 자동으로 설정합니다.

- Ubuntu 24.04 기반 KVM 호스트
- libvirt / qemu-kvm 가상화 계층
- XDR Sensor 가상 머신
- NAT 또는 L2 브리지 기반 Sensor 네트워크
- PCI 패스스루 기반 SPAN 트래픽 수집
- LVM 기반 전용 스토리지
- 커널 및 CPU 성능 튜닝

설치 프로그램은 다음 항목을 자동화하여 수동 개입을 최소화하도록 설계되었습니다.

- 호스트 OS 준비 및 성능 튜닝
- 네트워크 토폴로지 구성
- 스토리지 프로비저닝
- Sensor VM 라이프사이클 관리
- PCI 패스스루 기반 고속 패킷 수집

## 2. 설치 전 준비 사항 (필수 준비 단계)

### 시스템 요구사항

설치 프로그램 실행 전에 다음 조건을 반드시 충족해야 합니다.

- **root 권한이 필요함**
- 설치 프로그램은 다음과 같은 시스템 수준 작업을 수행합니다.
  - 네트워크 설정 변경
  - 커널 및 GRUB 설정 수정
  - 디스크 및 파일 시스템 구성
  - 가상 머신 생성 및 수정

### 지원 운영체제

- **Ubuntu Server 24.04 LTS만 지원**

### 준비 단계

1. root 쉘로 전환합니다.

```bash
sudo -i
```

2. 현재 디렉터리에 설치 스크립트를 다운로드합니다.

```bash
curl -O https://raw.githubusercontent.com/xdr-labs/OpenXDR-KVM-Installer/main/Sensor-Installer.sh
```

3. 실행 권한을 부여합니다.

```bash
chmod +x Sensor-Installer.sh
```

4. 설치 프로그램을 실행합니다.

```bash
./Sensor-Installer.sh
```

## 3. Sensor 네트워크 모드

설치 프로그램은 서로 다른 운영 요구사항을 충족하기 위해 두 가지 Sensor 네트워크 모드를 지원합니다.

### NAT 모드

- KVM 호스트와 Sensor VM이 하나의 외부 IP 주소를 공유
- libvirt 내부 NAT 네트워크(`virbr0`) 사용
- Sensor VM에 고정 내부 IP 할당
  - 기본값: `192.168.122.2`
- 다음 이유로 설치 및 관리 시 추가적인 주의가 필요함
  - 외부 접근이 간접적으로 이루어짐
  - 포트 포워딩 및 관리 트래픽 흐름을 고려해야 함

#### 대표적인 사용 사례

- Lab, POC 및 운영 환경
- 외부 노출이 제한된 단순한 배포 환경
- IP 자원이 제한된 환경

> 관리 인터페이스는 NAT 모드, SPAN NIC은 Bridge 모드로 구성할 수 있습니다.

![NAT 관리 인터페이스와 Bridge SPAN 구성 예시](/images/Sensor-Installer/2.png)

### 브리지 모드

- Sensor VM이 **전용 L2 브리지**를 통해 연결됨
- Sensor 트래픽이 KVM 호스트와 완전히 분리됨
- 고성능 물리 NIC 필요
- Appliance CLI는 Sensor 브리지에 ACL을 적용할 수 없음

#### 권장 사용 시나리오

- 고성능 Sensor 배포가 필요한 경우
- 10GbE 이상의 인터페이스를 사용하는 환경
- 보안 정책상 호스트와 Sensor 인터페이스의 엄격한 분리가 필요한 경우
- 운영 환경에서 고성능 Sensor 노드를 배포하는 경우

> 관리 인터페이스는 Bridge 모드, SPAN NIC은 PCI 패스스루 모드로 구성할 수 있습니다.

![Bridge 관리 인터페이스와 PCI Passthrough SPAN 구성 예시](/images/Sensor-Installer/3.png)

## 4. SPAN 연결 방식

설치 프로그램은 배포 환경에 따라 두 가지 SPAN 연결 방식을 지원합니다.

### PCI 패스스루 (기본 방식)

- 물리 SPAN NIC을 Sensor VM에 직접 패스스루
- 최대 패킷 처리량과 최소 지연 시간 제공
- 가상 스위칭 계층을 완전히 우회

#### 주요 특징

- 표준 PCI 패스스루 방식만 사용
- BIOS에서 IOMMU 활성화 필요
- 대부분의 물리 환경에서 기본값이자 권장 방식

### 브리지 모드 (SPAN)

- SPAN 트래픽을 L2 브리지를 통해 연결
- 주로 다음 환경에서 사용됨
  - 프라이빗 클라우드 환경
  - 가상화 또는 중첩 가상화 환경
  - PCI 패스스루 사용이 제한된 환경

이 방식은 성능을 일부 희생하는 대신 유연성과 호환성을 제공합니다.

### NIC 준비 및 설계 가이드라인

설치 과정에서 NIC 선택을 단순화하기 위해 설치 프로그램 실행 전에 필요한 NIC를 물리적으로 연결하는 것을 강력히 권장합니다.

설치 프로그램은 링크 상태를 기준으로 인터페이스를 식별하므로, 케이블이 연결되어 있으면 각 NIC의 역할을 명확히 구분할 수 있습니다.

![Sensor SPAN NIC 선택 화면](/images/Sensor-Installer/4.png)

## 5. 설치 프로그램 탐색 및 실행 모델

### 메뉴 탐색 방법

설치 프로그램은 대화형 메뉴 기반 인터페이스를 제공합니다.

- **Spacebar / ↓** : 앞으로 스크롤
- **↑** : 뒤로 스크롤
- **q** : 도움말 또는 가이드 화면 종료

### 상태 인식 실행 방식

설치 프로그램의 실행 상태는 다음 경로에 저장됩니다.

```text
/root/xdr-installer
```

완료된 단계가 기록되며, 이를 통해 설치 프로그램은 다음을 수행할 수 있습니다.

- 재부팅 후 자동으로 이어서 실행
- 이미 완료된 단계 건너뛰기
- 선택한 단계의 안전한 재실행

모든 설치 상태를 초기화하려면 다음 명령을 실행합니다.

```bash
rm -rf /root/xdr-installer
```

### DRY-RUN 모드

- 기본값: `DRY_RUN=1`
- 모든 작업은 시뮬레이션으로만 수행
- 실제 시스템 변경은 적용되지 않음

실제 배포 전에 반드시 다음과 같이 설정해야 합니다.

```text
DRY_RUN=0
```

메뉴 **3) Configuration**에서 설정합니다.

## 11. BIOS 및 플랫폼 설정

다음 BIOS 옵션이 활성화되어 있는지 확인하십시오.

- Intel Virtualization Technology
- VT-d / IOMMU
