# AIO & Sensor KVM Installer 사용자 가이드

![AIO & Sensor KVM Installer 전체 설치 흐름 개요](/images/AIO-Sensor/1.png)

## 개요

이 페이지는 **AIO + Sensor 설치를 처음부터 Appliance 초기 설정 완료까지 끝낼 수 있는 독립형 Runbook**입니다. 제품별 하드웨어 기준, KVM 배포, AIO 초기화, Data Lake Storage, Sensor 등록·승인, Receiver 검증까지 모두 포함합니다.

문서 기준 OS는 Ubuntu Server 24.04 LTS입니다. 설치 후 설정만 빠르게 다시 확인하려면 **[AIO & Sensor 초기 구성](/ko/installers/aio-sensor-initial-configuration)**을 사용할 수 있습니다.

### 아키텍처 개요

Stellar Cyber OpenXDR 플랫폼은 KVM 가상화를 사용하는 단일 물리 서버에 배포됩니다.

설치 프로그램은 다음 구성 요소를 자동으로 생성하고 구성합니다.

- Ubuntu 24.04 기반 KVM 호스트
- libvirt / qemu-kvm 가상화 계층
- AIO 가상 머신 (Data Platform + Analyzer 통합)
- Sensor 가상 머신(들)
- NAT 기반 가상 네트워크
- SPAN 트래픽을 위한 PCI Passthrough
- AIO 및 Sensor 워크로드를 위한 LVM 기반 스토리지
- CPU affinity 및 커널 수준 성능 튜닝

설치 프로그램은 다음 작업을 자동화하여 반복적인 수동 설정을 줄이도록 설계되었습니다.

- 호스트 OS 준비 및 튜닝
- 네트워크 구성 및 변환
- 스토리지 레이아웃 생성
- 가상 머신 라이프사이클 관리
- PCI Passthrough 및 CPU pinning과 같은 성능 중요 설정

## 2. 설치 전 준비 사항 (필수 준비 단계)

### 시스템 요구사항

설치 프로그램을 실행하기 전에 다음 조건이 충족되어야 합니다.

- **root 권한이 필요함**

설치 프로그램은 다음과 같은 저수준 시스템 작업을 수행합니다.

- 네트워크 재구성
- 커널 및 시스템 튜닝
- 디스크 및 파일 시스템 설정
- 가상 머신 생성 및 수정

### 문서 기준 운영체제

- 이 한국어 가이드는 **Ubuntu Server 24.04 LTS** 기준입니다.
- Legacy Ubuntu/OpenXDR 조합은 현재 Source Installer와 대상 릴리스 지원 범위를 별도로 확인하십시오.

## 3. 준비 단계

설치 프로그램을 준비하기 위해 다음 단계를 수행합니다.

1. root 쉘로 전환합니다.

```bash
sudo -i
```

2. 현재 디렉터리에 설치 스크립트를 다운로드합니다.

```bash
curl -O https://raw.githubusercontent.com/xdr-labs/OpenXDR-KVM-Installer/main/AIO-Sensor-Installer.sh
```

3. 실행 권한을 부여합니다.

```bash
chmod +x AIO-Sensor-Installer.sh
```

4. 설치 프로그램을 실행합니다.

```bash
./AIO-Sensor-Installer.sh
```

## 4. NIC 준비 및 설계 가이드라인

### 관리 NIC

관리 NIC는 다음 용도로 사용됩니다.

- KVM 호스트에 대한 원격 접속
- AIO 웹 인터페이스 접근
- 외부 관리 트래픽 처리

### Sensor 네트워크 모드

- **NAT 모드만 지원**
- 기본 KVM `virbr0` 네트워크를 사용하여 구현됨
- 이 설계는 배포를 단순화하고 운영 리스크를 줄임

### SPAN 연결 방식

- **PCI Passthrough만 지원**
- 브리지 기반 SPAN 연결은 지원되지 않음
- BIOS에서 IOMMU 활성화 필요
- PCI Passthrough는 Sensor 워크로드에 대해 가장 높은 패킷 캡처 성능을 제공

### NIC 준비 및 설계 가이드라인

설치 중 NIC 선택을 단순화하기 위해, 설치 프로그램 실행 전에 필요한 NIC를 물리적으로 연결하는 것을 강력히 권장합니다.

설치 프로그램은 **링크 상태를 기준으로 인터페이스를 식별**하므로, 케이블이 연결되어 있으면 각 NIC의 역할을 명확히 구분할 수 있습니다.

![NAT uplink NIC 선택 화면](/images/AIO-Sensor/3.png)

## 5. 설치 프로그램 탐색

설치 프로그램은 Whiptail로 구현된 대화형 메뉴 기반 인터페이스를 제공합니다.

### 탐색 방법 안내

- **Spacebar 또는 아래 화살표(↓)**: 메뉴 항목 간 이동
- **Enter**: 선택
- **q 또는 ESC**: 도움말 화면 종료 또는 이전 메뉴로 돌아가기

### 상태 인식 실행 방식

설치 프로그램은 **상태 인식 방식(state-aware)**으로 동작합니다.

설치 상태는 다음 경로에 저장됩니다.

```text
/root/xdr-installer
```

- 완료된 단계가 기록됨
- 재부팅 또는 중단 이후 다음 미완료 단계부터 재개됨

모든 설치 상태를 초기화하고 처음부터 다시 시작하려면 다음을 실행합니다.

```bash
rm -rf /root/xdr-installer
```

### 필수 재부팅 단계

설치 프로그램은 다음 단계 이후 자동으로 시스템 재부팅을 수행합니다.

- **STEP 03 – 네트워크 변환 (netplan → ifupdown)**
- **STEP 05 – 커널 및 시스템 수준 튜닝**

이 재부팅은 필수입니다. 절대로 건너뛰지 마십시오.

재부팅 후 수행 절차:

1. 서버에 다시 로그인
2. 설치 프로그램 재실행
3. 메뉴 1 선택

설치 프로그램은 자동으로 이어서 실행됩니다.

### 메인 메뉴 옵션 개요

#### 1. Auto Execute All Steps

- 다음 미완료 단계부터 모든 단계를 자동 실행
- 재부팅 후 마지막 완료 단계부터 자동 재개
- 권장 용도
  - 초기 설치
  - 재부팅 후 이어서 진행

#### 2. Select and Run Specific Step Only

- 개별 단계를 독립적으로 실행
- 권장 용도
  - AIO VM 재배포
  - Sensor VM 재배포
  - 네트워크 변경
  - 이미지 업데이트
  - SPAN 설정 변경

#### 3. Configuration

설치 파라미터를 구성합니다.

- `DRY_RUN` (default: `1`)
- `AIO_VERSION`
- `SENSOR_VERSION`
- `SENSOR_NET_MODE` (`nat` only)
- `SPAN_ATTACH_MODE` (`pci` only)
- ACPS credentials
  - username
  - password
  - URL

#### 4. Full Configuration Validation

전체 시스템 구성을 검증합니다.

검사 항목:

- KVM
- AIO VM
- Sensor VM
- 네트워크
- SPAN
- 스토리지

상세 로그와 함께 오류 및 경고를 표시합니다.

#### 5. Script Usage Guide

- 내장 도움말 가이드 표시

#### 6. View Log

- 설치 로그 파일 표시

#### 7. Exit

- 설치 프로그램 종료

## 9. 필수 AIO & Sensor 초기 구성

Full Configuration Validation에서 VM 배포를 확인한 뒤 다음 Appliance 설정을 완료하십시오.

### 9.1 KVM 고정 Network

- AIO: `192.168.122.2/24`
- Sensor/MDS: `192.168.122.3/24`
- Gateway: `192.168.122.1`
- DNS: `8.8.8.8`

### 9.2 AIO 구성

`aella / changeme`로 로그인하고 비밀번호를 변경한 뒤:

```text
set interface management ip 192.168.122.2/24
set interface management gateway 192.168.122.1
set interface management dns 8.8.8.8
set role AIO
set cluster_name AIO
set cluster_size 1
set cm 192.168.122.2
set otp <YOUR-OTP>
reset
```

초기화 후:

```text
show status
```

Platform이 Ready/Healthy 상태인지 확인합니다.

### 9.3 AIO Data Storage 추가

```text
show storage
add storage blk vdb
show storage
```

<Warning>
`add storage blk`는 선택한 Device를 Format합니다. 승인 전에 `vdb`와 예상 용량을 확인하십시오.
</Warning>

GUI의 **System → DATA MANAGEMENT → Data Management → Advanced**에서 `/es-data-lvm`으로 Migration하고 **System → DATA MANAGEMENT → Data Lake**에서 **Data Storage Space**를 확인합니다.

### 9.4 Sensor 연결

Sensor에서 `aella / changeme`로 로그인하고 비밀번호를 변경한 뒤:

```text
set interface management ip 192.168.122.3/24
set interface management gateway 192.168.122.1
set interface management dns 8.8.8.8
show interfaces
set hostname <UNIQUE-SENSOR-HOSTNAME>
set cm 192.168.122.2
show cm
```

필요한 경우:

```text
set proxy http://<PROXY-IP>:<PORT>
set tenant_id <TENANT-ID>
```

**CM Controller = 192.168.122.2**, **Status = Established**를 확인하고 `quit`로 종료합니다.

### 9.5 NTP, Sensor 승인, Receiver

- Sensor NTP/Timezone 구성
- Stellar Cyber에서 Sensor Authorization 수행
- Receiver는 DA-Master가 아니라 **AIO/DP**를 가리켜야 함
- Sensor Profile이 해당 Receiver를 사용하는지 확인
- `show logforwarder` 출력이 없으면 Receiver 설정부터 확인

### 9.6 접속

```text
console aio
console mds
```

- AIO SSH: **2222**
- MDS SSH: **2223**

### 9.7 최종 체크리스트

- Full Configuration Validation에 미해결 FAIL이 없음
- AIO = `192.168.122.2/24`, Sensor = `192.168.122.3/24`
- AIO `show status`가 Ready/Healthy
- `vdb` 추가 및 `/es-data-lvm` Migration 완료
- Sensor Hostname이 고유함
- Sensor `show cm`이 `192.168.122.2`에 **Established**
- NTP/Timezone 및 Sensor Authorization 완료
- Receiver와 Sensor Profile 정상
- 기본 비밀번호 변경 완료

설치 후 설정만 빠르게 다시 보려면 **[AIO & Sensor 초기 구성](/ko/installers/aio-sensor-initial-configuration)**을 사용하십시오.

## 10. 하드웨어 및 소프트웨어 요구사항

실제 실행 전에 다음을 확인하십시오.

- Ubuntu Server 24.04 LTS
- root 권한
- CPU Hardware Virtualization 활성화
- Sensor PCI Passthrough용 VT-d/IOMMU 활성화
- 의도한 AIO/Sensor Sizing을 수용할 CPU와 Memory
- 충분한 OS/VM Storage 및 전용 Data Lake Disk
- Management Connectivity와 필요한 Sensor SPAN NIC
- Package 및 Image 다운로드용 Network Access
- Network 전환 전 Console 또는 Out-of-Band Access

**[Ubuntu 24.04 설치 가이드](/ko/getting-started/installing-ubuntu-24-04)**는 추가 참고용이며 제품별 Hardware 가이드는 이 페이지에 요약되어 있습니다.

## 11. BIOS 및 플랫폼 설정

Intel VT-x / AMD-V와 Intel VT-d / AMD-Vi (IOMMU)를 확인하십시오. 문서의 Sensor PCI Passthrough 구성에 필요합니다.
