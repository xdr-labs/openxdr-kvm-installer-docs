# 상태 및 로그

현재 문서화된 DP, Sensor, AIO + Sensor Installer는 실패나 Reboot 이후 Resume할 수 있도록 Persistent File을 사용합니다.

## Root 실행

Root로 실행할 때 일반적으로 다음 경로를 사용합니다.

```text
/root/xdr-installer/
└── state/
    ├── xdr_install.conf
    ├── xdr_install.state
    └── xdr_install.log
```

Sensor와 AIO Script는 Root가 아닌 경우 실행 User의 Home Directory를 사용할 수 있습니다.

## File 역할

- `xdr_install.conf` — Persistent Operator Configuration
- `xdr_install.state` — Completed Step 및 Last-run Metadata
- `xdr_install.log` — Execution / Troubleshooting Log

<Warning>
Configuration과 Log에는 환경별 정보가 포함될 수 있습니다. 외부 공유 전 Credential, Private Address, Infrastructure 정보를 Redact하십시오.
</Warning>
