# 설치 단계 비교표

아래 표는 현재 Installer Source의 Step Array를 기준으로 합니다.

| Step | DP | Sensor | High-performance Sensor | AIO + Sensor |
| ---: | --- | --- | --- | --- |
| 1 | HW/NIC/Disk | HW/NIC/CPU/Memory/SPAN | HW/NIC/CPU/Memory/SPAN | HW/NIC/SPAN |
| 2 | HWE Kernel | HWE Kernel | HWE Kernel | HWE Kernel |
| 3 | NIC/ifupdown/Network | NIC/ifupdown/Network | NIC/ifupdown/Network | NIC/ifupdown/Network |
| 4 | KVM/libvirt | KVM/libvirt | KVM/libvirt | KVM/libvirt |
| 5 | Kernel/KSM/Swap | Kernel/KSM/Swap | Kernel/KSM/Swap | Kernel/KSM/Swap |
| 6 | SR-IOV Driver + NTPsec | libvirt Hook + NTPsec | libvirt Hook | libvirt Hook + NTPsec |
| 7 | DL/DA LVM | Sensor LV + Download | Sensor LV + Download | AIO LVM |
| 8 | Hook + OOM Recovery | Sensor Deploy | Sensor Deploy | AIO Download |
| 9 | DP Image/Script | Sensor Network/SPAN | PCI Passthrough/CPU Affinity | AIO Deploy |
| 10 | DL-master Deploy | Appliance CLI | Appliance CLI | Sensor LV + Download |
| 11 | DA-master Deploy | — | — | Sensor Deploy |
| 12 | SR-IOV/CPU/Passthrough | — | — | PCI Passthrough/CPU Affinity |
| 13 | Appliance CLI | — | — | Appliance CLI |
| 14 | NFS Backup Config | — | — | — |

<Note>
Step ID는 Persistent State Contract의 일부입니다. State를 수동으로 건너뛰거나 변경하면 Resume 동작이 깨질 수 있습니다.
</Note>
