# 배포 후 운영

Installer가 완료되면 정상 OpenXDR 운영으로 전환하기 전에 Host와 VM을 검증합니다.

## Host 확인

- libvirt Service 정상 여부
- 예상 VM Definition 존재 여부
- Management Address와 Route
- 예상 LVM Volume
- Time Synchronization

## Topology별 확인

- DL/DA/AIO/Sensor VM 상태
- Management Connectivity
- Sensor VM의 SPAN/Passthrough Interface
- DP 경로의 SR-IOV/VF Assignment
- Storage Mapping

## Appliance CLI

Installer Family에는 DP Appliance CLI Package 설치 Step이 포함되어 있습니다.

</Card>

## 배포 Evidence 보관

Change-control 정책에 따라 Installer Log와 최종 Configuration Summary를 보관합니다. 외부 공유 전 Secret을 제거하거나 Redact하십시오.
