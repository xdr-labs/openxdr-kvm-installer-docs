# High-performance Sensor Installer

`6000-Sensor-Installer.sh` is the High-performance Sensor deployment path using **dual VMs, NUMA-aware CPU placement, NAT management networking, and PCI Passthrough SPAN**.

## Current 10-Step Workflow

| Step | Task |
| ---: | --- |
| 1 | Hardware / NIC / CPU / Memory / SPAN NIC selection |
| 2 | HWE Kernel installation |
| 3 | NIC rename / ifupdown transition / network configuration |
| 4 | KVM / libvirt installation and baseline configuration |
| 5 | Kernel parameters / KSM / swap tuning |
| 6 | libvirt hook installation |
| 7 | Sensor LV creation + image/script download |
| 8 | Sensor VM deployment |
| 9 | PCI Passthrough / CPU Affinity |
| 10 | DP Appliance CLI package installation |

## Performance Model

This installer treats NUMA visibility, CPU placement, and direct device assignment as important parts of a high-performance Sensor deployment.

## Network / SPAN Constraints

The current `6000-Sensor-Installer.sh` uses:

- Sensor management network: **NAT**
- SPAN attachment: **PCI Passthrough only**
- high-performance placement: NUMA-aware CPU Affinity

If your virtualized environment requires Bridge SPAN, review the **[Standard Sensor Installer](/installers/sensor)** first.

Before execution, verify IOMMU, IOMMU groups, dedicated SPAN NICs, and NUMA/CPU placement.

## State Location

When run as root, this installer currently uses `/opt/xdr-installer`. This differs from the other current installer family, which generally uses `/root/xdr-installer` for root execution.
