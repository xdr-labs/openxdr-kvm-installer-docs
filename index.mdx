# OpenXDR KVM Installer

OpenXDR KVM Installer automates the host-side work required to deploy Stellar Cyber OpenXDR components on KVM. Instead of manually assembling libvirt, storage, networking, VM images, passthrough, CPU placement, and reboot state, operators use a guided `whiptail` workflow with persistent state and validation.

<Tip>
**First deployment?** Start with **[Choose an Installer](/getting-started/choose-installer)**, review **[Requirements](/getting-started/requirements)**, keep **DRY_RUN enabled**, and then follow the installer-specific guide.
</Tip>

## What the installer automates

| Area | Automation |
| --- | --- |
| Hardware | CPU, memory, disks, NICs, virtualization and IOMMU discovery |
| KVM stack | KVM/libvirt installation and base configuration |
| Networking | Management, NAT/bridge, SR-IOV, SPAN and passthrough workflows where applicable |
| Storage | LVM-backed VM storage preparation |
| VM deployment | Image preparation, VM definition and deployment |
| Performance | CPU affinity, NUMA-aware placement and PCI passthrough where applicable |
| Lifecycle | Step state, reboot handling and resume |
| Safety | DRY_RUN, explicit confirmations and full configuration validation |

## Common operating flow

```text
Inspect hardware
  → validate configuration
  → keep DRY_RUN enabled for the first pass
  → configure installer inputs
  → run all steps or one selected step
  → reboot when the installer requires it
  → run the same installer again to resume
  → complete post-deployment validation
```

<Warning>
The installers can change networking, storage, kernel configuration, virtualization settings, and VM definitions. Review the target host carefully and use DRY_RUN before real execution.
</Warning>
