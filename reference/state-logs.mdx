# State & Logs

The documented DP, Sensor, and AIO + Sensor installers keep persistent files so deployments can resume after failures or reboots.

## Root Execution

When run as root, these installer families normally use:

```text
/root/xdr-installer/
└── state/
    ├── xdr_install.conf
    ├── xdr_install.state
    └── xdr_install.log
```

The Sensor and AIO scripts may use the invoking user's home directory when they are not run as root.

## File Roles

- `xdr_install.conf` — persistent operator configuration
- `xdr_install.state` — completed-step state and last-run metadata
- `xdr_install.log` — append-oriented execution and troubleshooting log

<Warning>
Configuration and logs can contain environment-specific information. Redact credentials, private addresses, and sensitive infrastructure data before sharing.
</Warning>
