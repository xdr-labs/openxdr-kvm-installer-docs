# Post-deployment Operations

After the installer completes, verify the host and deployed VMs before handing the environment over for normal OpenXDR operation.

## Validate the host

Confirm:

- libvirt is healthy
- expected VM definitions exist
- management addressing and routes are correct
- expected LVM volumes are present
- time synchronization is healthy

## Validate the selected topology

Check the items relevant to the installer:

- DL/DA/AIO/Sensor VMs are present and running as expected
- management connectivity is reachable
- SPAN or passthrough interfaces are attached to the correct Sensor VM
- SR-IOV/VF assignments are correct for DP paths that use them
- storage mappings match the intended topology
