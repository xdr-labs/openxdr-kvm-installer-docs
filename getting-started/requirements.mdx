# Requirements

Exact sizing depends on the selected OpenXDR component and target workload. Validate the current installer configuration and Stellar sizing before production deployment.

## Common prerequisites

- Ubuntu Server supported by the selected installer
- Root privileges for system-changing installation steps
- Intel VT-x or AMD-V hardware virtualization enabled in BIOS
- Intel VT-d or AMD-Vi when SR-IOV or PCI passthrough is required
- `whiptail` installed
- Sufficient CPU, memory and local storage for the target VMs
- Management connectivity to the host
- Additional SPAN/data interfaces for Sensor deployments as required
- Network access to required packages and Stellar component images
- Change/recovery plan before changing host networking or storage

## OS guidance

The current project documentation covers Ubuntu Server 20.04, 22.04 and 24.04 for the Sensor/AIO families. The DP installer also contains support for older DP deployment paths, including Ubuntu 16.04-based environments. Always verify the selected DP/component version against the active installer before proceeding.

## Common Sensor/AIO baseline

The project README identifies **12 vCPU**, **16 GB memory**, and approximately **100 GB free storage** as a common starting baseline for standard Sensor/AIO paths. Actual production sizing can be higher and the installers perform resource calculations where applicable.

## BIOS checklist

```text
Hardware virtualization: Enabled
IOMMU / VT-d / AMD-Vi: Enabled when passthrough is required
NUMA visibility: Required for the high-performance Sensor path
```

## Host safety checks

<Warning>
Network and storage steps are potentially disruptive. Confirm console or out-of-band access before changing NIC names, switching network configuration, or provisioning disks.
</Warning>

Run the installer's **Full Configuration Validation** before real execution. Blocking failures must be corrected before deployment.
