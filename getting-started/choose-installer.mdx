# Choose an Installer

Choose one installer based on the deployment target, topology, and network requirements.

| Installer | Use it for | Primary network characteristics | Current step count |
| --- | --- | --- | ---: |
| `DP-Installer.sh` | DL-master / DA-master Data Processor | NAT + Cluster Bridge/SR-IOV | 14 |
| `Sensor-Installer.sh` | Standard Modular Sensor | NAT/Bridge + SPAN PCI/Bridge | 10 |
| `AIO-Sensor-Installer.sh` | Integrated AIO Data Processor + Sensor | NAT + Sensor SPAN PCI Passthrough | 13 |

## Decision Guide

<Steps>
  <Step title="Need DL and DA Data Processor VMs?">
    Use **DP-Installer.sh**. It includes DP image preparation, DL/DA deployment, SR-IOV/CPU affinity, Appliance CLI installation, and NFS backup configuration.
  </Step>
  <Step title="Need only a Standard Modular Sensor?">
    Use **Sensor-Installer.sh**. It handles Sensor storage, VM deployment, and network/SPAN configuration.
  </Step>
  <Step title="Need AIO and Sensor on one host?">
    Use **AIO-Sensor-Installer.sh**. It deploys AIO first, then continues with the Sensor path on the same host.
  </Step>
</Steps>
